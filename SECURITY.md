# Security policy

## Reporting a vulnerability

Please do not disclose tokens, credentials, private repository data, or vulnerability details publicly.

Use GitHub private vulnerability reporting:

https://github.com/Pleo2/agent-lowmem-action/security/advisories/new

Describe the affected version, impact, and minimal reproduction without including a live credential. Public issues are appropriate only after sensitive details have been removed.

## Scope

Agent Lowmem Action makes read-only GitHub REST API requests and writes only to GitHub-provided workflow summary and output files. A command recommendation is not a guarantee that repository code is safe to execute.
