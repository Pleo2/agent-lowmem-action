# Support

For usage questions, reproducible bugs, and conservative feature requests, open an issue:

https://github.com/Pleo2/agent-lowmem-action/issues

Include the Action version, the closed `result` output, and a minimal description of the repository evidence involved. Remove tokens, private repository names, and other secrets before posting.

For vulnerabilities or accidental secret exposure, use the private route in [SECURITY.md](SECURITY.md) instead of a public issue.
